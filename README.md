# 🎵 Sinfonia da Memória (Audio & Color Memory Game)

> Um jogo de memória interativo inspirado no clássico Genius, desenvolvido com **HTML5**, **Tailwind CSS**, e a poderosa **Web Audio API** para síntese sonora em tempo real.

## ✨ Sobre o Projeto

O **Sinfonia da Memória** desafia o jogador a memorizar e repetir sequências crescentes de sons e cores. Cada botão colorido corresponde a uma nota musical específica (acorde de Dó Maior), criando uma experiência sinestésica envolvente e divertida diretamente no navegador, sem a necessidade de arquivos de áudio externos!

---

## 🚀 Funcionalidades

- **Síntese Sonora Dinâmica:** Utiliza a Web Audio API nativa para gerar frequências puras de áudio em tempo real (sem dependência de arquivos `.mp3` ou `.wav`).
- **Design Moderno & Responsivo:** Estilizado com **Tailwind CSS** e fontes do Google Fonts (*Poppins*), apresentando efeitos de vidro (`backdrop-blur`), gradientes vibrantes e feedback visual imediato.
- **Dificuldade Progressiva:** A velocidade da sequência aumenta sutilmente a cada nível, testando os reflexos e a memória de curto prazo do jogador.
- **Placar & Níveis em Tempo Real:** Acompanhamento dinâmico do nível atual e pontuação acumulada.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **Tailwind CSS** (Estilização via CDN e utilitários modernos)
- **JavaScript Moderno (ES6+ Classes)** (Lógica do jogo, gerenciamento de estado e manipulação do DOM)
- **Web Audio API** (Osciladores e envelopes de ganho para áudio programático)
